SAVED GRAPH · LINEAR RC TRANSIENT
Backward-Euler time-domain run
The graph supplies connections; you explicitly map every component to supported R/L/C/V/I models, ordered pins, values, source waveforms, and reactive initial conditions, or exclude it with a reason. RLC mode requires explicit inductor initial currents. Fixed-step backward Euler is numerically dissipative; timestep adequacy and convergence are not checked. This is not nonlinear/SPICE equivalence or design approval. Placeholder mapping is illustrative only.

  
SAVED GRAPH · EXPLICIT R/V/I MAPPING
Map circuit graph to linear DC MNA
The saved graph supplies net connectivity only. You must choose each component's supported model type, both ordered pin numbers, and explicit numeric value/unit. Every component must be mapped or excluded with a reason. Descriptions, part numbers and attached datasheets are never parsed into values; excluded parts make the solved network partial.

  
LINEAR DC OPERATING POINT · EXPLICIT NETLIST
Modified nodal analysis
Supports ideal resistors and independent DC voltage/current sources with explicit units. Enter the netlist directly; there is no saved-graph or datasheet conversion. The placeholder is illustrative and is not submitted unless you enter it. This does not model semiconductor I-V curves, transients, parasitics, or thermal behavior.

  
CLOCK BENCHMARK · INTEGER DIVIDER MATH
Divider modulus candidate
Enter the actual source frequency, desired tick rate, and source tolerance. The nearest positive integer modulus is reported with rate/drift bounds. This does not select a counter IC, MCU timer, reset circuit, or implementation.

Clock timebase error
Enter the nominal tick rate after any divider, its target rate, and a symmetric tolerance in ppm. No oscillator, crystal, MCU, divider, or datasheet values are inferred. This is rate-error arithmetic, not digital simulation or an accuracy guarantee.
